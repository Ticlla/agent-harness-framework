Harness Framework

Plan once, prove on one item, run the full batch — with gates at every step and sign-off before anything ships.

Arrow keys / Space / click Next

Problem

Why not just ask the agent?

  • Ask to fix 50 things — often 35 get done, then “done.”
  • No written plan, no proof every item ran, no gate before merge.
  • Expensive to undo partial batches or silent skips.

Harness framework = engineered workflow + verification + human sign-off.

Concept

Skill vs harness

Skill = one step done well. Harness = provable flow around the steps.

Concept

SkillHarness

Conductor

Skills play instruments; harness holds the score.

Kitchen

Skill = recipe. Harness = banquet prep + taste-test + chef sign-off.

Decision

Three-question rule

3 x YES -> harness framework  |  Any NO -> use a normal skill

Clarification

Build

Four meta-skills

designer-> implementer-> validator-> Run batch

Build

What each stage produces

StageOutput
designerHARNESS_DESIGN.md (plan + Mermaid)
implementerOrchestrator skill or rules-only artifacts
validatorSmoke on 1 item + VALIDATION_REPORT.md
enhancerRepair loop on failure or drift

Validator is the only stage that runs the harness before production trust.

Runtime

What the orchestrator runs

Per item: delegate -> gates must pass -> loop -> human review (HITL) -> merge
